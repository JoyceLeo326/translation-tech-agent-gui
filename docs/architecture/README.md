# 译述架构说明

本目录用于项目答辩、二次开发和交付验收，内容与当前桌面程序的真实实现对应。

- [智能体架构](AGENT_ARCHITECTURE.md)：模型接入、任务路由、术语约束、多模态能力与密钥安全。
- [工作流架构](WORKFLOW_ARCHITECTURE.md)：文字、图片、Word、音视频、批量整合及 Coze 多模型精译流程。

程序在无密钥时可执行文件提取、术语检索、DOCX 回填、资源验收与本机语音等确定性任务；翻译、视觉识别、转写和 Coze 工作流需要连接相应服务。未连接时界面只说明缺少的条件和下一步，不生成替代译文；服务返回的结果仍需经过人工审校后进入最终交付。
