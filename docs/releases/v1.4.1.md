# 译述 YISHU v1.4.1｜可复现交付与明确运行状态

本版修复 Windows 干净构建中的统一交付问题，并收紧所有模型相关结果的来源边界。

- 从受版本控制的音频成品稳定生成 PCM WAV，并校验 WAV 结构、帧数与采样参数。
- 将术语工作流、音视频说明与交付日志纳入统一成品区；干净 CI 生成 81 个可用文件。
- 未连接文本模型时停止翻译并给出模型接口连接步骤，不再返回替代文本。
- 未连接 Coze 时只显示已校验的 18 节点、28 连接结构与配置状态，不生成译文。
- 测试文本只填入输入区，结果区明确标记尚未执行。
- 同步更新桌面实机截图、Vercel 产品页与架构说明。

发布资产由 GitHub Actions 的 Windows Build 成功制品生成；发布页同时提供 ZIP 的 SHA256 文件。
